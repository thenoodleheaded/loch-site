# loch-site

The public pages for **Loch** — the privacy policies and the support page that the App Store
and Google Play listings link to. Served by GitHub Pages at
<https://thenoodleheaded.github.io/loch-site/>.

This repo holds only the site. It is generated from `docs/` in the Loch app repo, which stays
private; run `scripts/publish-site.sh` there to push an update. Edit the pages there, not here.
